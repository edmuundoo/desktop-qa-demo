# Фактическая проверка

Дата: 30 сентября 2026 года (Europe/Samara).

- ОС: Darwin 26.3.1, архитектура arm64.
- Python: 3.13.3.
- PySide6 / Qt: 6.11.2.
- pytest: 8.4.2.
- pytest-qt: 4.5.0.
- allure-pytest: 2.16.2.
- Allure Report: 3.19.1, Node.js: 25.1.0.
- Режим Qt: offscreen.

Команда:

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -v --alluredir=allure-results --clean-alluredir
```

Результат: **1 passed in 0.75s**, код завершения 0.
Полный вывод: `test-result.txt`. Исходные результаты: `allure-results/`.
HTML-отчёт: `allure-report/index.html`.
Версии Python-зависимостей: `requirements-tested.txt`,
npm-зависимостей: `package-lock.json`.

HTML успешно сформирован командой `npm run report` (код завершения 0)
и проверен в браузере: один успешный тест, шаги и вложения доступны.
Включены шаги, ожидаемые и фактические данные, два скриншота и журнал сервиса.

Подтверждён сценарий двух обновлений через кнопки Qt и реальный TCP-сервис
в отдельном процессе: ровно 10 сигналов, все поля соответствуют ожидаемым,
нет повторяющихся ID, второй снимок заменяет первый при обратном порядке строк.

Первый запуск в изолированной среде завершился ошибкой setup:
среда запрещала bind локального TCP-сокета (PermissionError).
После разрешённого запуска с доступом к 127.0.0.1:2001 тест прошёл.

На Linux тест пока не выполнялся. Добавлена конфигурация GitLab CI для
будущего запуска на Linux; успешность этого job пока не подтверждена.
